# 설계 결정 기록 (devlog)

구현 중 "왜 이렇게 했는지"가 사라지지 않도록, 되돌리기 어려운 결정만 날짜별로 남깁니다.
기존 계획의 `docs/devlog.md` 단일 파일을 이 디렉터리로 대체했습니다 — 결정 하나가 파일 하나여야 링크로 참조할 수 있기 때문입니다.

## 규칙

- 파일명: `YYYY-MM-DD-슬러그.md` (날짜는 **결정한 날**)
- 기록 대상: 되돌리는 비용이 큰 것 — 스키마, 저장소 선택, 인증 방식, 인프라 구조, 비용 부담 주체
- 기록 대상 아님: 일반적인 리팩터링, 네이밍, 라이브러리 버전 올림
- 결정이 나중에 뒤집히면 원본을 지우지 말고 **상단에 `> 대체됨: [새 결정](...)`을 추가**합니다

## 템플릿

```markdown
# <결정 한 줄>

- 날짜 / 상태(확정 | 검토 중 | 대체됨) / 관련 문서

## 배경
## 선택지
## 결정
## 근거
## 트레이드오프
## 영향
```
